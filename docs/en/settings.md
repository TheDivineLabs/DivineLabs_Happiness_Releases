# Happiness Client settings

Click the DivineLabs logo to open the panel. Hold and drag it to move it.

| Section | Settings |
| --- | --- |
| **Client → Screenshots** | Capture the window, game or an area. Set shortcuts or add quick buttons by the logo. |
| **Client → Metrics** | Select the metrics you need and drag the panel by its header. |
| **Client → Flash quality** | Auto, low, medium or high. The first change may require a game reload. |
| **Game → General** | Effects and labels fix profile for supported game resources. Takes effect on the next load. |

Screenshots are saved locally. Imgur uploads are optional and require a Client ID. Logs are available from the home panel.
