# Как проверяем Client

| Проверка | Что она показывает |
| --- | --- |
| Комплектность архива | Файлы совпадают с контрольными суммами выпуска. |
| Установщик | Встроенный пакет проходит проверку целостности. |
| Изолированная игровая сцена | Проверяем запуск, ввод, перезагрузку и изменённые настройки. |
| Живой бой | Отдельно сверяем изображение, реакцию интерфейса и поведение под нагрузкой. |

О результатах и известных ограничениях пишем в [заметках к выпуску](../NEWS.md). Для сравнения производительности нужны сопоставимые сцены и настройки.

Если нашли проблему, укажите версию Client и Windows, вариант установщика и шаги повторения. [Отправить отчёт](https://github.com/TheDivineLabs/DivineLabs_Happiness_Releases/issues/new/choose)

## Выпуск 0.3.0
