# Настройки Happiness Client

Нажмите на логотип DivineLabs. Чтобы переместить его, удерживайте кнопку мыши и перетащите.

| Раздел | Что можно настроить |
| --- | --- |
| **Клиент → Снимки** | Снимок окна, игры или области. Можно назначить сочетания и вывести быстрые кнопки рядом с логотипом. |
| **Клиент → Метрики** | Выберите нужные строки панели и перетащите её за заголовок. |
| **Клиент → Качество Flash** | Авто, низкое, среднее или высокое качество. При первой смене может понадобиться перезагрузка игры. |
| **Игра → Общее** | Профиль «Исправления эффектов и подписей» для поддерживаемой версии игрового ресурса. Применяется при следующей загрузке. |

Снимки сохраняются локально. Отправка в Imgur включается отдельно и требует Client ID. Журналы можно открыть с главной панели.
