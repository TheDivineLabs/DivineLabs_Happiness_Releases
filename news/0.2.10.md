# Два варианта Client: с WebView2 и без него

2026-10-31 · 0.2.10

Client теперь выпускается в двух вариантах. Для каждого доступны установщик EXE и portable ZIP.

- Со встроенным WebView2: использует закреплённую копию компонента входа из папки приложения.
- Без встроенного WebView2: меньшая загрузка; для входа через ВК нужен системный Microsoft Edge WebView2 Runtime. Если его нет, окно входа объяснит, что установить.

CEF и Flash для игры входят в оба варианта. Функции Client одинаковы; дополнительные игровые модули Plus в него не входят. Режим входа явно задан поставкой и сохраняет отдельный профиль. При смене режима может потребоваться повторный вход.

Оба режима и сообщение об отсутствии системного компонента проверены на собственной тестовой странице без аккаунтов. Реальный вход в ВК требует пользовательской проверки.
