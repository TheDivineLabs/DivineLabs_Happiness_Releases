# Two Client variants: with and without WebView2

2026-10-31 · 0.2.10

Client is now available in two variants, each with an EXE installer and a portable ZIP.

- With bundled WebView2: uses a pinned copy of the sign-in component from the application folder.
- Without bundled WebView2: a smaller download; VK sign-in requires an installed Microsoft Edge WebView2 Runtime. If it is missing, the sign-in window explains what to install.

Both variants include CEF and Flash for the game and provide the same Client features. Additional Plus gameplay modules are excluded. The package explicitly selects the sign-in mode, which uses a separate profile. Switching modes may require signing in again.

Both modes and the missing-system-runtime message were checked on a synthetic page without accounts. Real VK sign-in still needs a user check.
