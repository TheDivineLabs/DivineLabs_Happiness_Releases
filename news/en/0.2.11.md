# Client 0.2.11: Flash animation fixes

2026-11-01 · 0.2.11

Two fixes are enabled: repeated starts of identical effects within one buff update are coalesced, and animation label lookup reads the label list once instead of twice.

The Performance window now has a Flash animation fixes switch. Restart the application after changing it. If a game update changes the resource version, the client uses the original game file.

EXE installers and portable ZIPs are available with or without bundled WebView2. Client excludes automation and MCP commands.

Both fixes were tested together on an owned Flash scene and used in a heavy battle. Stutters during mass proton grenade impacts remain. No measured FPS comparison is available yet; mass animation changes will be evaluated separately.
