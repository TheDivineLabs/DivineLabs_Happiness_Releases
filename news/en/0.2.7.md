# Standalone Client without additional modules

2026-10-30 · 0.2.7

Client now has its own application. The additional Plus gameplay modules are excluded from its EXE.

Client retains the resizable window, themes, floating panel, links, game screenshots, system tray and local measurements. Its main EXE is about 4.16 MiB, compared with about 15.80 MiB for Plus. These are file sizes, not FPS or RAM measurements.

The new shell was checked on a separate test scene. Full VK sign-in in this shell still needed a user check at this release.
