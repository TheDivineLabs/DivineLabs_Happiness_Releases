# Local performance measurements

2026-10-30 · 0.2.6

Added a Performance section with 60-second recording, manual stop and local report export.

Recording can continue after the settings window closes. It is disabled by default and captures CPU usage, memory and available Flash frame intervals. Game logic intervals are not presented as visible FPS. Reports are not uploaded automatically.

Comparative optimization results have not been published.
