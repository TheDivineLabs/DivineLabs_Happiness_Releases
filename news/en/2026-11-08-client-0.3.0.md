# Happiness Client 0.3.0

2026-11-08 · 0.3.0

The free Happiness client for manual play. Installer and portable packages are available with bundled WebView2 or the system runtime.

- VK sign-in, a resizable game view and a configurable reload shortcut.
- Window, game and region screenshots, a draggable metrics panel and per-session logs.
- Flash quality settings and a separate Game → General section for the fix profile.
- Installed copies select the matching update installer and verify its SHA-256. To move from a previous release, use the new installer or a separate portable folder.
