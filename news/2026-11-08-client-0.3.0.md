# Happiness Client 0.3.0

2026-11-08 · 0.3.0

Единый бесплатный клиент Happiness для ручной игры. Установщик и portable доступны со встроенным WebView2 или с системным Runtime.

- Вход через ВК, адаптивное окно игры и перезагрузка по сочетанию клавиш.
- Снимки окна, игры и выбранной области, перемещаемая панель метрик и журнал по сессиям.
- Настройка качества Flash и отдельный раздел «Игра → Общее» для профиля исправлений.
- Установленная версия подбирает установщик обновления и проверяет SHA-256. С предыдущих выпусков перейдите через новый установщик или отдельную portable-папку.
