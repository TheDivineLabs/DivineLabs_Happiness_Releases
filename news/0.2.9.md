# Встроенный компонент входа через ВК

2026-10-30 · 0.2.9

В Client 0.2.9 включён Microsoft WebView2 Fixed Version Runtime 156.0.4314.56 x86. Он поставляется в установщике и portable; отдельная системная установка WebView2 не нужна.

- Окно входа использует конкретную копию движка из папки приложения. Его версия и путь процесса проверяются перед открытием страницы.
- При отсутствии или повреждении компонента показывается ошибка.
- Профиль встроенного движка отделён от системного. После перехода может потребоваться повторный вход.

Размер загрузки увеличился из-за включённого движка. Он обновляется вместе с клиентом. Совместимость с будущими изменениями Windows и сайта ВК проверяется отдельно.

Проверено на собственной тестовой странице: запуск встроенного движка, обработка возврата входа, отключение звука и запрет сохранения паролей. Настоящий вход в новой версии требует пользовательской проверки.
