The ClientPlus development build now has a panel in the corner of the game showing its current status, waiting period and two most recent action log entries. It lets clicks pass through and is excluded from game screenshots.

If startup is blocked because Flash is not loaded or the game layout has not been confirmed, the reason is shown on screen. Russian error messages from the VK sign-in component now use the correct encoding.

These changes are part of ClientPlus development. No new public Client or ClientPlus binaries have been published; automation after a real sign-in is still being verified.
