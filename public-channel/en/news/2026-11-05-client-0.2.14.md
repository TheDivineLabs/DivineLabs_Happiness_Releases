Client 0.2.14 is prepared with an independent launcher, startup failure reports and renderer crash recovery. The DivineLabs maintenance wizard handles updates, repair and removal. Updates preserve Data and wait for this copy of the game to close.

Installer and portable packages are available with bundled WebView2 or without it. The latter requires a system Microsoft Edge WebView2 Runtime only for VK sign-in. Older packages without the new launcher require one full installation or extraction.

Accepted Flash fixes are enabled by default for the supported game resource. Additional experiments, MCP, diagnostics and automation are excluded from Client. ClientPlus is not part of the public distribution. VPN and game-server disconnects are not fixed by this release.
