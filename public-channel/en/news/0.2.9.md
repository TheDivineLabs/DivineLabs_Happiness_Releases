Client 0.2.9 includes Microsoft WebView2 Fixed Version Runtime 156.0.4314.56 x86 in both the installer and portable archive. A separate system WebView2 installation is not required.

- The sign-in window uses a specific runtime copy from the application folder. Its version and process path are checked before opening the page.
- Missing or damaged runtime files produce an error.
- The bundled runtime has a separate profile. You may need to sign in again after switching.

Downloads are larger because they include the runtime. It is updated with the client. Compatibility with future Windows and VK changes requires separate testing.

A synthetic page test covered runtime startup, the sign-in callback, mute and disabled password saving. Real sign-in in this version still needs a user check.
